# 可复用虚拟数据预览

此目录固定保存合成夹具和预览工具，后续UI试验直接复用，无需每次在忽略目录重写一套服务器。`fixtures/catalog.mjs`生成144个稳定身份的示例条目，覆盖多日期、长文件名、图片/动图/视频、常规/COS、作者、来源、收藏及观看进度；没有用户数据、外部媒体或真实设备配置。

## 启动与隔离

先由AI下载并核对指定提交的云端Web产物，再运行：

```powershell
node tools/ui-preview/server.mjs --dist build/ui-preview.local/candidate/web-dist
```

默认只监听`127.0.0.1:19474`，拒绝使用8420；可通过`--port`指定其他隔离端口。必须显式提供已构建Web目录，工具不会本地编译、猜测服务地址、连接数据库或转发API。AI在Windows后台启动辅助进程时使用隐藏窗口，并复用固定的`build/ui-preview.local/`存放当前候选、来源清单、PID与截图；这些本机材料不入库。浏览器仅在用户要求看效果时显示，结束预览后关闭本次辅助进程。

页面带“虚拟数据预览”标识，支持`?theme=light`/`?theme=dark`。API在内存中提供推荐/COS、排行、相册筛选/日期分组/分页、统计、历史及偏好演示。图片封面由代码绘制；视频仅有合成封面与时长，不包含真实视频解码素材。支持的点赞/收藏/偏好等演示写入只影响当前进程，重启恢复；上传、删除和未实现的API明确返回错误，不伪装成功，不写入真实文件。

## 验证范围

这是UI夹具，不实现或替代生产推荐、统计及领域公式；数据与请求形状参照[OpenAPI](../../api/openapi.yaml)及[浏览专题](../../docs/api/browse.md)。`browse.mjs`只模拟演示所需的常用筛选、排序、排自身候选及分页；不能用它证明完整领域兼容性、真实视频播放或NAS性能。

`api.mjs`也供Web的`e2e/browse.spec.ts`复用，避免人工预览和浏览器回归重复维护不同数据。云端Web job运行：

```text
node --test ../tools/ui-preview/preview.test.mjs ../tools/ui-preview/server.test.mjs
```

回归锁定分页身份/日期总数、COS隔离、筛选候选、内存写入隔离、未知API与路径/链接逃逸保护；浏览器场景验证换批、键盘打开、筛选清空及失败重试。自动测试只走云端，具体执行边界见[协作规范](../../AI_README_FIRST.md#验证与交付)。

浏览器路由夹具中不模拟关闭即重连的短SSE响应，该组场景直接阻断SSE请求；否则反复“连接成功”会让应用刷新缓存，干扰失败重试场景。人工预览服务器保持真正长连接，既有SSE专项回归继续独立验证生产连接逻辑。

统计汇总和趋势桶共用合成分类拆分，均携带静图/动图/视频及常规/COS字段；回归检查分类守恒和各窗口汇总，避免虚拟数据被客户端协议完整性检查拒绝。

维护页提供独立递增的合成appRxBytes/appTxBytes及空回收站/异常列表，仅用于展示本服务流量卡；这是虚拟计数，不能证明生产HTTP字节埋点。生产埋点由云端HTTP回归覆盖。

“浏览回顾”预览返回固定合成结果，包含守恒的合成类型停留与24小时堆叠示例，覆盖摘要进入详情、保留窗口、全部窗口不造比较、失败重试与真实零记录。夹具不复制生产统计公式，生产计算由服务端回归保护。
