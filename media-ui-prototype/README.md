# media-ui-prototype（历史 UI 原型，已归档）

> **归档说明（2026-09-09）**
>
> 本目录是绮梦影库多端版（qimeng-media）桌面 UI 的**历史静态原型**，用于早期视觉验证与侧边栏/顶栏/卡片流方案敲定。
>
> - **正式实现已迁至 `../web/`**（React + Vite + PWA，M2 起为主线）。

> - 本目录仅作设计参考与历史存证保留，不参与构建、不入库运行链路。

## 目录内容（历史快照）

| 路径 | 说明 |
|---|---|
| `index.html` / `style.css` / `app.js` | 纯 HTML/CSS/JS 静态原型 |
| `serve.mjs` | 本地静态预览服务（`node serve.mjs 8099`） |
| `covers/` | 本地化封面/头像占位素材 |
| `data/` | 卡片与 DOM 结构 JSON |
| `sidebar-handoff.md` | 当时的侧边栏任务书（历史文档） |

## 与正式实现的关系

原型验证通过的视觉方向（顶栏高度、卡片流、三段式侧边栏等）已由 `web/` 按正式架构重写实现；二者无代码依赖，原型不可直接拷贝进 `web/`。
