# LEGACY_REQUIREMENTS - 旧版沉淀需求清单

> 来源：旧项目 QimengMedia（Android 单机版）`docs/CHANGELOG.md` v1.14~v1.19（2026-08-09 ~ 08-26）的审查/重构/修复记录。
> 本清单只记录**需求、交互语义、体验约束**——NAS 版（qimeng-media）技术与 UI 实现完全重写，不继承任何实现细节；每一条都来自旧版真机验证过的功能或修过的坑，NAS 版做对应功能时**必须**对照。
> 使用：M2（Web）/ M3（算法）/ M4（Android）实现前逐条过一遍；与用户最新拍板冲突时以用户为准。
> 最后更新：2026-08-26

## A. 标签管理（详情页标签弹窗）【M2 Web·M4 Android】

| 需求 | 来源 |
|---|---|
| 标签区**多行自适应换行**，不单行横滑：标签少一行、多则自动 2~N 行；弹窗外层整体可上下滚动，消除"标签多时拥挤" | v1.19 8-26 |
| 当前标签**按"最近添加置顶"排序**（新添加的标签排在前面）；"其他标签"按标签创建时间倒序；增删后排序立即体现 | v1.19 8-26 |
| **筛选面板/统计等其他场景保持名字序**，只有详情页标签弹窗用关联时间序 | v1.19 8-26 |
| 增删标签**即时反馈**：删除后 chip 不得短暂残留复活、快速连续增删不卡顿（UI 永远以数据源为准，不得出现写入前旧状态） | v1.19 8-26 |
| 空态：当前标签为空显示"暂无标签" | v1.19 8-26 |
| 详情页删除标签只解除**当前文件**的关联；标签的全局删除在筛选面板 | v1.19 8-26 |

## B. 视频缩略图代表帧策略【M1 服务端·M2/M4 展示】

**状态**：已合并进 `docs/DOMAIN_RULES.md` §11（2026-08-26）；M1 现有代码实现仍为旧策略，升级排入 M2 开工时随缩略图展示需求一并落地（旧版 8-24 用 ffprobe 实测用户参考库 376 个视频 0 个带内嵌封面，证实体验 100% 来自代表帧）：

| 需求 | 来源 |
|---|---|
| 抽帧优先级：**内嵌封面优先 → 按视频时长 35% 偏移取代表帧**（对齐 Windows 资源管理器 Icaros 体验，35% 帧构图最有"封面感"）→ 系统缩略图兜底 | v1.18 8-24 |
| 黑白/极端帧检测：采样 100 点，全部 <15 判黑、全部 >240 判白；不合格按比例向两侧扩散（35%→25%→45%→15%→55%→5%→65%→0ms） | v1.18 8-24 |
| 取不到时长时短路 0ms 帧，不重复取同一帧 | v1.18 8-24 |
| 抽帧位置策略变更后**旧缩略图缓存必须失效重建** | v1.18 8-24 |
| 列表/详情实时显示用首帧（中段 seek 慢会加剧滑动掉帧）；代表帧用于预生成缓存——两者分工是旧版验证过的性能决策 | v1.18 8-24 |

## C. 搜索维度【M2 Web·M4 Android·M3 作者体系】

| 需求 | 来源 |
|---|---|
| 搜索支持**常规作者维度**（非 COS 作者）：搜作者名能命中其关联文件；一个文件关联多作者时任一命中 | v1.17 8-20 |
| 补全建议含"作者"类型标签，且**只显示实际有文件的作者**（不显示孤立作者名） | v1.17 8-20 |
| 作者改名/新增/关联变化会触发补全索引与结果刷新 | v1.17 8-20 |

## D. 统计口径【M3】

| 需求 | 来源 |
|---|---|
| 浏览统计**唯一真相源 = 按"文件×天"聚合**（每文件每天一行，无限保留）；数字卡、趋势、窗口排行全部同源同口径，主页面与详情页一致 | v1.14 8-09 / v1.15 8-11 |
| 趋势"全部"= **真全量、动态分桶**：≤12 周按周、12 周~24 月按月、更长按季，从最早数据铺到当前，全量不丢弃，桶之和=总和，与数字卡口径一致 | v1.16 8-16 |
| 周对齐：**从周一算起，与系统 locale 无关**（zh-CN 下周日不能滚到下周一） | v1.16 8-16 |
| 数据不足 2 个周期时补前导 0 桶保证折线可画；空数据显示"暂无趋势数据" | v1.16 8-16 |
| 统计详情页四种模式：分类型趋势（类型卡+来源卡多系列对比同时间轴）、常看文件、常看作者与标签排行、分布；**时间范围胶囊全局联动**（数字卡/趋势/排行随 7 天/30 天/全部过滤） | v1.14 8-09 |
| 常看排行拆分：**作者 Top15、标签 Top10 两张独立卡**；主页面外部保持混合 Top3 预览；作者点击跳作者文件页、标签点击跳搜索页（携带标签作为初始关键词） | v1.16 8-16 / v1.14 |
| 播放计数：**同一详情页一次打开只计一次**（预览→播放→退预览→再播放不重复）；浏览计数会话级去重（横滑切回不重复计） | v1.14 / v1.15 / 8-14 巡检 |

## E. 浏览/播放交互【M4 Android·M2 Web】

| 需求 | 来源 |
|---|---|
| 视频**同源续播**：同一文件未播完退出再进，保留播放进度继续（仅非结束态） | 8-14 巡检 |
| 时间轴标签弹窗**打开时暂停播放**（保证标记时间点与实际画面一致） | v1.15 8-10 |
| 超大图（>4096px、8K、50MB 级）观看：坚持"始终原图不降采样"——用户强偏好；超大图滑动轻卡为已知代价，**用户已拍板接受，勿再推销降采样/代理图方案** | v1.16 8-16 |
| 后台长任务（扫描/TXT 导入/刷新）的 UI 反馈必须**生命周期安全、可取消**：用户切走页面/销毁后不得崩溃（回调判空/随页面取消） | v1.16 8-19 |

## F. 空态与健壮性【M2/M4】

| 需求 | 来源 |
|---|---|
| 排行列表/排行榜空数据显示"暂无数据"占位（不可点击、不高亮），不能只剩标题 | 8-16 审查 |
| 点赞/收藏后再进详情页、返回首页/收藏页/作者页：**收藏监听自动刷新**（详情页切换收藏，收藏页/作者列表页立即更新）；点赞返回首页排行应重排，**浏览统计不驱动首页重排**（否则内容跳动） | 8-14 巡检（含当日回归修复） |
| 网格列数调整**持久化**（各列表页，重启不丢、备份可恢复） | 8-14 巡检 |
| 详情页冷启动空库：有限次数重试后退出，不闪退 | 8-16 审查 |

## G. 数据安全原则【全局·M1 已有大部分】

| 需求 | 来源 |
|---|---|
| 扫描入库**宁残留、不可误删**：目录空查询/授权撤销 ≠ 目录为空（`.nomedia`、Android 16 非标准目录 MediaStore 恒查不到），异常场景跳过该源本轮清理 | 8-14 巡检 / v1.15 |
| 同名/重编码文件（元数据或 mtime/size 变化）必须走"更新"而非"未变忽略"，元数据不得永久陈旧 | v1.15 / 8-14 |
| 删除媒体 = 回收站（ADR-0007 已有）；删除文件同步清理其缩略图/统计/历史/标签关联 | v1.16 8-14 / 8-16 审查 |
| TXT 作者导入解析：**数字开头的作品文件名不误判为编号行**（如 `2077 帕南.png` 是作品不是作者块） | 8-09 / v1.15 |
| 备份/迁移：写失败保留旧备份完整（不先删后写）；导入时空主键/空外键跳过；多表导出用一致快照；偏好数值导入钳制（禁用越界/NaN） | 8-16 审查 / v1.15 |

## H. 性能体验（用户可感知项）【M2/M4】

| 需求 | 来源 |
|---|---|
| 列表滚动流畅：分页**提前加载**（距已加载底部 ≤6 项触发，加载发生在滑动中，不在触底瞬间同步风暴）；滚动期间暂停后台缩略图生成；视频首帧不被双重解码 | v1.15 8-11 |
| 扫描进行期间后台缩略图预生成**降速**（明显降并发），扫描结束自动恢复——避免主线程/UI 卡顿 | v1.16 8-16 |
| 缩略图缓存**不按数量上限淘汰**（按数量砍会导致每次启动重缓存固定比例的稳态抖动）；只清理"已不在库"的孤儿缓存（写入超 24h 才动，避免误删刚生成的）；库新增文件后缩略图尽快可用（增量刷新也触发预生成） | v1.16 8-14 |
