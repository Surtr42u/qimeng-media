# GUIDE_UI - 当前 UI 维护约束

> 本文整理本仓已记录的现行交互约束与定位，作为日常 UI 维护入口。业务语义由 [领域专题](DOMAIN_RULES.md)定义，接口由 OpenAPI 定义，视觉与本端契约由模块 README 定义。旧仓 GUIDE_UI 是历史来源，不再是必须可访问的外部唯一规格书。
> 本文不宣称完整复刻旧版所有页面；未写明的交互先核对用户要求、相关测试及实现，再补充有效约束，不把历史推测成当前需求。

## 共同约束

- UI 只呈现状态和触发客户端逻辑层动作，不直调 API、不复算推荐/统计/匹配。
- 加载、空态、失败、重试、未保存离开和重复提交防护按所在流程核对；多步保存按成功步骤记账，失败可重试。
- 原件查看保持原始字节与直链；缩略图是独立预览，缓存身份及数据新鲜度按领域/API 专题。
- Android图片取色复用舞台原图，不再另取原件；当前图就绪后才按有界预算串行预取邻图，暂停/离屏取消。预取限制不影响完整原图查看与缩放，生命周期和预算见[Android入口](../android/README.md#详情原图加载与预取)。
- 常规/COS 分区、同维 OR/跨维 AND、收藏与历史默认范围按 [筛选](domain/filtering.md)、[作者隔离](domain/authors.md)及 API browse，不在组件复制规则。
- 资产编辑负责作者关联/来源维护；来源=获取渠道，与作品出处不同。作者管理保留媒体文件，COS 作者由目录扫描管理。
- 标签多选时保持候选标签顺序与占位，选中/取消不移出候选池、不置顶或改变字号/宽度。Android 详情管理将全量池放在动态勾选摘要之前，勾选图标预留固定宽度、颜色短过渡；摘要 × 仍立即解绑已有文件关联，池内点选在保存后生效。Web 现有筛选/管理池保持原位选择。
- App/Web 作者管理提供名称与别名、来源/出处编辑、关注和删除；来源指获取渠道、平台或个人链接，不参与作品匹配。常规作者编辑复用现有接口与 TXT 真相，COS 仅浏览与关注。列表按可见项读取认证头像，缺图保留首字；独立卡片展示名称、单独COS标记、文件数与管理动作。Web沿用紫青玻璃，Android采用浅灰页底、白色卡面与细描边；关注按钮紧凑描边，Material菜单显式使用卡面色、圆角和轻阴影，来源/改名配图标，删除分隔并标红。来源先读取再开放整体替换保存，清空须显式保存；读取失败可重试、保存失败保留草稿，关闭未保存编辑先确认，保存中禁重复提交与关闭。Web 名称/来源分类分别保存，当前草稿保存后再切换，避免跨端多请求部分成功的误报。
- 作者档案直接融入原作者作品集合页，详情和作者管理入口共用；不增加独立底部Tab。普通/COS网络资料独立于TXT来源与目录身份；头像缺失显示首字。主卡呈现头像、身份、X简介、关注与本地文件数，译文可用时默认中文，在X入口/详细资料同排右侧切换中文与原文。编辑X资料时按语言切换单个简介框并保留草稿，修改原文会清空旧译文以待重新核对。编辑页保留作者上下文、卡片化字段、字数与未保存状态，无改动时保存禁用。其他平台、完整整理简介、账号ID、核验记录和维护进入独立详情子页。详情默认只读，双端统一为X资料、基础资料、账号来源和作品订阅四块，各自点击编辑才显示该块输入项，保存或取消返回概览；完整核验说明和检查记录按需展开。手机使用全屏单块编辑页、可滚动正文及固定底部操作区，适配键盘和系统安全区，独立编辑窗口的系统栏图标明暗跟随背景。窄屏Web编辑底栏为悬浮按钮保留侧向空间，操作纵向排列。候选核对单独展示候选影响的五个字段，失败保留草稿，取消脏草稿需确认；Web媒体详情作者卡同样展示头像。原筛选、媒体网格及返回保持。刷新不得覆盖人工资料，候选先审核填草稿再显式保存；修订冲突/失败保留草稿并明确提示。维护开关默认关闭，动态需要真实RSS/Atom，不把尚未检查、失败或无源显示成零更新，也不自动下载作品。
- 作者页内容分为本地作品与作者新作两项。本地作品沿原筛选和媒体网格；新作区仅消费显式配置的作品发布专用订阅。暂无可靠来源时提供作者发布入口，来源失败与暂无记录分别呈现。新作范围为明确作品发布，普通日常发文、转推及回复须在接入来源时区分。Android详细资料以全屏子页呈现，关闭保留父页滚动与选择状态。关注与动态追踪各自独立；追踪在资料设置中核实身份、配置订阅并保存后生效。动态默认三条、按需展开，在外部浏览器查看原帖；无源、关闭、未检查、失败与已取空记录分别说明，不标虚假未读/未收藏。取消身份核实同时关闭两类自动检查；候选仍需人工审核保存。
- 设置页提供明确的浏览偏好、影库与作者资料入口；Web 不再展示设置顶部重复分类快捷栏，作者/来源维护链接沿既有路由，App 外观行回显当前主题/导航材质、推荐行回显已读取的预设或加载状态。客户端特有设置保持各端现有职责。

- 备份仅接收本项目当前v2；选旧v1/缺版本/未知版本时明确拒绝，缺viewEvents数组不发请求。两端确认摘要按原生事件数，不把聚合统计当事件回放；提示按事件身份/关联规则合并、不删除媒体原件，不笼统承诺全部元数据只增不减。

## 浏览回顾与相关交互

- 数据页以“浏览回顾”取代“此刻发现”，定位个人浏览报告，不再给出候选封面、换组或内容名次。Web/桌面展示首次浏览、再次浏览、浏览内容与活跃天数摘要，进入独立报告可查看兴趣变化与24小时活跃分布；详情保留所选7/30/90天或全部窗口，返回数据页携带同一窗口。Android主页面只显示“浏览回顾”名称入口，进入现有统计详情路由后按所选7/30天或全部窗口加载报告，主页面不预取。首访/回访与等长窗口比较均消费服务端值，口径见[统计专题](domain/statistics.md#浏览回顾独立于推荐和排行)。原首页推荐及周期榜保持原有用途；旧发现接口仅供已安装旧客户端兼容。
- 回顾优先呈现浏览时长，按用户参考图使用大号时长/当前窗口标题、上方00/06/12/18刻度、24列堆叠柱形、细网格、底部图片/视频/动图时长图例；三类互斥值均消费服务端，颜色沿用参考图的蓝/黄/绿。悬停/点击柱形显示小时、停留及open次数，Web支持左右/Home/End，不另放滑杆。小字说明是已记录的详情停留，非视频播放时长。精确小时来源及窗口定义见统计专题。
- 丰富内容放在浏览时长和类型构成，保留探索/回访总数；兴趣变化按用户最终确认的无图形卡片呈现，去除叠片、双点轨道、箭头/图标与图例。按服务端changePoints正负分为更多关注/较少关注，空组不显示、组内保持服务端顺序，不重新计算或选择兴趣项。每卡默认显示名称、作者/标签和“在浏览中的份额增加/减少”，避免将份额变化冒称浏览次数增减；详情/收起为文字入口，各卡独立展开上期/本期份额、次数与升降百分点。Web沿用紫青玻璃token，支持键盘、展开状态与关联详情区域；Android沿用中性主题、圆角卡面和轻描边，提供读屏展开状态。Web桌面右侧预留悬浮入口空间，窄屏卡片使用完整内容宽度，名称换行、详情按可用宽度自动换列；只做展示分组和格式化，不改既有open/兴趣公式。
- 回顾读取失败须明确重试，有缓存时标记旧内容，不冒充零记录；真实零记录仍展示报告。全部窗口没有前一时段；任一比较窗口无浏览时明确说明，不能伪造兴趣升降。作者与标签可多关联，份额不是互斥分布。
- Web长搜索词预留清空与放大镜的完整区域，失焦省略，聚焦仍可水平编辑，清空后焦点留在输入框。
- Web扫描自动/手动模式切换立即提交当前设置；读取完成前及保存中不重复切换，失败保留草稿并提示。手动数量仍显式保存；未保存/保存中离开有提示，保存与退出位于右侧推荐偏好卡片下方，桌面按钮底边与左侧界面卡片底边对齐；窄屏随该卡片排列，不另开侧栏或底部吸附遮挡。 操作区为壳层刷新/回顶部悬浮按钮预留右侧空间，窄屏可换行，不能遮挡点击。
- Web视频网页/原生全屏均有右上角退出入口；暂停时清晰可见，鼠标移到底部唤出并保持控制栏，Esc可退出网页全屏。网页全屏补偿html zoom，视频不保留详情舞台高度上限。Android现有播放器桥同样增加独立全屏退出入口，暂停不自动隐藏控制栏，鼠标底边悬停唤出控制栏；不新增播放器内核或AndroidView桥。
- 本端浏览事件经服务端确认（含离线补发）后失效Web统计/周期榜/历史缓存；浏览回顾随统计查询一同刷新。

## Web/PWA

定位：[web/README](../web/README.md)。React 页面经 hooks 获取数据；Aurora Glass 的 token/主题/降级、zoom 补偿只在该 README 维护。

- 侧栏返回以首页为终点，到首页后停用；只后退到当前壳内确认过的历史条目，直达子页、刷新或未知历史回落首页，不能退到站外。仍经路由处理未保存离开确认；浏览器自身后退行为不改。
- 数据管理入口卡保留左侧语义图标和整卡链接，不显示右上角跳转箭头。

- 数据页窗口联动总浏览/播放/停留、浏览占比及统计作者/标签榜；静图/动图/视频互斥，榜单沿用入口窗口与服务端排序。错误单独显示并可重试，有限榜单不标为全量；统计语义与 Android 同源。
- 数据页与“我的”沿用维护页的Aurora Glass卡片/标题/紫青色，统计活动与当前库存明确分区。数据窗口保存在range参数，完整榜单沿用窗口；各板块独立加载/失败/重试，旧协议仍明确提示升级，不因单一榜单失败遮住全页。窗口覆盖数量直接展示服务端viewedFilesCount/viewedAuthorsCount/viewedTagsCount，不以Top5或平均数反推。
- 数据页底部三张榜单卡采用一致的紧凑单行高度；标题、说明及同序分隔线横向对齐。作者总览每行只显示作者名，不再显示文件数副标题；顶部作者总数/关注数、原排序及跳转保留。
- “我的”保留关注/收藏/历史及原分页、收藏时间排序和常规/COS默认范围；分区tab与历史筛选q保存在URL并替换当前条目，返回恢复原分区。Tab支持左右/Home/End，榜单与历史卡支持键盘打开；取消关注失败保留列表并提示，失败不误报为空。历史筛选明确只查已加载文件名，匹配数与已加载数分开显示，不用“共N项到底了”冒充筛选结果；筛选期间停止自动续页并提供加载更多，非筛选仍自动续页，错误可单独重试。个人概况不虚构管理员身份，未知库存显示缺省而非零。
- 上传页的小返回按入口区分：服务与维护的入库入口返回服务与维护，数据管理入口返回数据管理，URL记录已知来源、刷新仍保留；作者管理补同风格小返回。
- 浏览历史条目沿用首页媒体流的无外框排版，仅封面保留圆角，不显示左上完成角标；浏览时间、观看进度、来源信息、键盘打开及分组分页行为保留。
- 首页顶部推荐/COS/排行榜使用紧凑分段导航，统一字号、间距及主色选中底；保留URL切换与排行周期逻辑，左侧主导航不变。窄窗口搜索与分类分行，避免遮挡；窗口按钮及桌面拖动契约保留。
- 首页推荐/COS在内容上方常驻“换一批”，热榜对应“刷新榜单”；仍复用原seed/刷新键与分页，不计算客户端排序。摘要只显示已加载条数，换批期间显示更新中，不将其写成全库数量。
- 相册标题展示服务端匹配数与已加载数，提供一键清空所有维度和高级筛选；维度选项可独立展开/收起，已生效筛选不强制撑开。首次读取失败在顶部提示，续页失败的重试入口放在已有列表末尾；均保留已有条目，不显示误导性的空相册提示。
- 首页/相册等共享媒体卡支持Tab聚焦及Enter/空格打开，名称与焦点环明确；鼠标打开与原批次详情导航保留。
- 上传工作台支持目录拖拽和队列，直传/分片分流及刷新恢复按 API files；作者编辑在资产编辑页。
- 上传内部把位置设置、可选作者来源、添加入口和任务结果分区；目录按需展开，作者来源折叠不清值，添加区常显本批摘要。尚未确认已有作者身份的回车结果须选定或清空后才能新入队；不把自由文字显示成已完成关联。任务卡展示入队快照及完整错误，窄窗口不依赖横向六列表格，清理已结束记录不删除媒体；仍选入即上传，不恢复暂存/开始上传步骤。
- 上传队列持久化初始化/读取/写入失败显示页面有效性与刷新风险；删除旧记录失败单独提示核对已入库文件。重试按钮只重试本地存储，保持传输与成功/挂靠事实，不自动重传。恢复跳过持久化终态标记，双重存储故障仍可能留下旧记录；uploadId 七天凭据边界不变。
- 刷新后重选上传文件时核对名称、大小及已有修改时间；不匹配留在待选状态并显示原因，防止把改写过的文件接到旧任务上。
- 详情展示、播放、时间轴、相册与管理页共享现行业务口径；库变更、成功备份导入及 SSE 重连会刷新统计/排行/历史等缓存，持续挂载页面不依赖重进刷新。SSE 机制查 API browse。
- 视频详情在双栏宽度下让右侧作者与推荐整体顶/底边对齐播放舞台，共用高度变量；推荐卡填满作者下方剩余高度。窄窗口回到上下排列及独立限高。详情页“接下来播放”保持标题/换批固定、列表内部滚动，键盘可聚焦滚动；换批/换资产在新数据提交后即时回到列表顶部，禁用旧行滚动锚定并取消在途平滑滚动，失败可重试且不显示虚假的空态，长标题保留完整提示。
- 视频详情播放器不再显示左上角“已看完”角标；完成判定、从头重播/断点续播和进度上报不变，浏览历史列表也不显示完成角标，进度数据保留。
- ConfirmDialog 的 busy/失败重试、路由拦截与 beforeunload 的未保存保护是现行交互防线。
- 设置页的界面/推荐偏好按内容宽度并排，窄区自动上下排列；清晰度与推荐预设用按文字宽度排列的紧凑按钮，不拉伸为整行。即时保存与原偏好语义保留。
- 设置保存期间允许继续编辑；响应只确认提交时的修订，后续草稿与失败草稿保留，初次查询/刷新不能覆盖输入。扫描并发默认自动，按服务端可用CPU/内存保守分配1–8库；可手动1–32库，同时作用于手动/轮询/监听的后续全库扫描，单库顺序和运行任务不变。缩略图长边仍为预留。单文件业务大小上限输入已撤下，空间/类型/路径与暂存总预算保留。
- 当前不展示快照调度卡；快照 API 能力仍在，不据旧截图/历史重建该 UI。
- 维护页采用紧凑仪表盘，保留既有紫青/玻璃美术。流量卡只采样本服务HTTP正文appRxBytes/appTxBytes，含趋势/峰值/累计/采样点提示；旧服务端缺字段提示升级，不使用全机网卡填充，速率按整B/s展示以免长小数撑破卡片，累计计数不取整，重复的独立网络大图已撤下；文件管理、回收站与上传仍跳转原路由，存储明细进入独立页面，概览不原位展开；客户端异常直接进入完整日志页，默认显示服务端保留的全部记录，不跳页内锚点或要求二次展开。服务器目录自动导入移到上传页高级入口，明确无人值守匹配及成功移走源文件，不与逐批作者/来源上传混淆；触发/失败/忽略/最近成功能力保留，折叠停定时轮询，后端通道未退役。监控/日志失败可重试并保留旧记录，缺失读数不伪零；按内容区宽度适配。维护任务中心为独立只读区块：状态筛选、沿 nextCursor 翻页与手动刷新，详情展示类型/状态/进度/时间/最近步骤与工件元数据，取消需二次确认；不创建任务、不显示任务载荷正文与工件正文，列表失败区别于空列表，终态任务不提供取消入口。
- 数据管理按任务分组，上传新文件与整理已有文件分开；整理页支持游标续页，批量只对已加载选集操作。换库/目录等待新列表，不把旧目录文件套上新目录动作；错误与空目录区分，键盘/触屏可用文件操作。上传仅向已知启用的目标入队，配置失败/暂停接收时阻止新任务；队列既有目标不受后续修改影响。作者挂靠按服务端能力，换作者清空批次来源。
- 库注册与扫描分步反馈，第二步失败保留已注册事实并提供单独重试；扫描受理不等于完成。停用前说明文件/记录保留，移除登记前说明收藏/标签/作者等关联影响；失败保留确认框。来源词表/镜像读取失败不开放保存，保存期间锁编辑、失败留草稿，来源/镜像共用未保存离开保护并可放弃修改；TXT/备份读取防重入，移除TXT片段先确认重建影响，冲突处理及v2限制保持。

## Android

导航/详情/播放器/上传的职责定位见 [Android 维护入口](../android/README.md#维护定位)；状态与生命周期仍各自单源，内部拆分不改变下列现行交互。

定位：[android/README](../android/README.md)。Compose → ViewModel → Repository，feature → core。地址经 ServerConfigDataSource，在线/本机模式共用 UI 与协议。

- 常驻层与跳板路由隔离 Tab 状态；悬浮胶囊底栏的空白区域消费触摸，避免穿透媒体卡片。
- 首页默认推荐与 COS 都由服务端推荐，COS 只取 COS 子集；下拉换 seed 重排，不用“已是最新”解释推荐换批。COS 显式筛选/排序时保留资产列表行为，重置筛选回推荐模式。小库或评分约束下换 seed 仍可能同序，不承诺每次内容必不同。
- 数据统计主/详情页读取服务端窗口汇总、互斥类型数量及未截断文件/作者/标签数，趋势所有类型/来源共用一次响应日期轴；失败为独立错误态并支持同档重试，不显示伪零值。
- 数据统计主页及详情的浏览趋势图不绘制背景网格线，保留折线、面积、数据点、日期标签和点选气泡；权威统计口径见 [统计专题](domain/statistics.md)。
- 搜索入口/建议/结果三态；结果区固定媒体类型（综合/视频/动图/图片）与分区（全部/常规/COS）两级选项。切换选项回顶，换词重置默认档位；映射仍按领域/API。
- 搜索结果卡标题显示完整文件名（含作品编号/组图页码），单行省略，悬停与读屏可获完整名；换搜索词期间显示「正在搜索…」加载态而不是旧词结果，同词内筛选/分区切换仍保留旧列表不闪；分区与高级筛选不变。详情页对 COS 资产标题显示作品名，另起一行展示完整文件名并可一键复制（剪贴板不可用/失败时提示手动复制）。普通浏览网格仍 cosWork 优先两行。
- Android 搜索结果每张图片/视频/动图缩略图下方显示一行短文件名（去扩展名、单行省略，保留作品编号与组图页码），不压缩缩略图比例、不改变网格列数；详情「详细信息」弹窗展示完整文件名并可一键复制（Clipboard + 提示）；保留双指缩放 2～5 列、分页、滚动与返回行为，内嵌 Go 与连接模式同一 API。
- 首页/搜索/库管理的挂起业务调用继续传播取消，不弹失败或启动普通失败重试；loading 只由当前请求释放。返回搜索入口即作废在途结果，注册成功与后续扫描分别记账。
- 作者 TXT 选择后由数据层先检查扩展名/声明大小，再有界读取并核对 JSON 请求字节（含转义），超限不出网；读取期间禁重入，失败可重新选择。限制见 [作者 API](api/authors.md)。
- 上传页按位置、可选关联、添加文件、归档与任务结果分卡，作者来源默认收起且保留配置，权限/格式长说明按需展开。空库可直达库管理，读取失败区别于空库并可重试；刷新目标列表不清空已选目录和待传文件，归档未配置可直达设置。SAF仍先预览/改名再点开始上传，系统分享仍直传。
- 上传入口为系统文件 SAF 与系统分享，后台 WorkManager；可配置归档文件夹及按库名一键上传。归档一键上传的说明/确认框明确：PC/NAS 确认入库后删除已上传的手机归档副本，本机上传保留；清理失败或文件变化时保留，在成功队列行与通知显示提示，不触发重传。单任务取消在持久化成功后展示“已取消”，失败明确提示重试；不级联取消后续队列。暂存区/收件箱旧流程已退役，不照历史恢复。
- 本机词表维护与两端词表同步为并集合并（ADR-0035）；旧单向覆盖方案仅历史参考。词表维护页保存成功后有静默回读（抹平服务端规范化差异）；初次加载或保存后回读期间的新草稿均受修订号保护，较慢旧响应不能覆盖。保存态先结束再发起回读，即时完成的规范化结果也能回填；回读期间可继续编辑，已保存结果与提示不因回读失败/取消变更为失败。
- 播放/图片复杂自绘 View 可经 AndroidView 桥接（ADR-0014 例外），使用时记交付清单；禁止搬旧 Kotlin 页面实现。

- “我的”按我的内容/影库与连接/使用偏好/关于组织入口；同组使用一个卡面，整行点击、长副标题换行，非交互版本信息不伪装成按钮。库存计数明确属于当前媒体库，未取得仍显示缺省。退出登录先确认，取消不改变登录态。
- 数据管理按入库与整理/词表与关联/备份与存储组织入口，作者TXT、备份及上传归档集中在资料备份与归档；上传操作仍在上传页，保持原目录权限及清理边界。备份/库管理/缓存子页简介明确任务范围，管理内容卡共用白卡/深色卡与日间轻影，提示横幅保留语义颜色。备份目录先设置再导入/导出，未选目录或任一导入导出进行中禁止重复文件操作；浏览补传与词表合并为独立操作，动作放说明下方适应窄屏。备份规则文案按当前v2的事件身份与文件匹配规则，不沿用v1批次重复累计提示。
- 外观页有顶栏返回与系统返回，返回“我的”恢复列表位置；主题和底栏材质使用整行单选与选中语义，纵向排列可适应窄屏/大字体，点选仍沿原偏好流生效。推荐偏好弹层独立滚动，四预设恒显、保存期间禁重复提交并显示进度，失败在弹层内回显并保留原选中项及重试入口，重试成功撤销旧错误提示；保存状态区常驻，进度出现/消失不推动选项。点击已生效项不重复保存，仍以成功响应更新已保存项。
- 服务器页区分当前连接与默认登录端，默认项整行单选不切换当前连接；充电扫描整行切换且仅本机显示。归档设置顶栏固定在滚动内容之外。

### 登录模式与服务器选择

服务器设置提供回到NAS寻找的入口，仍经原登出/登录确认。Android登录页使用「本机 / NAS或电脑」双模式按钮，NAS默认自动发现并展示连接卡。单候选自动填入，多候选保留选择；最近5个成功地址按新到旧保留，先寻找历史再搜索当前网络，发现与记忆状态分别呈现。手填收在备用入口，显式选择/手填不会被迟到发现覆盖。输入与主要操作可随键盘滚动，不固定居中而裁掉底部内容；日间使用既有轻影和中性色，深色跟随主题。发现/连接中显示对应状态，发现结果不能冒充认证成功。实现/权限和失败边界见[Android入口](../android/README.md#登录与局域网连接)。

## 资料备份与归档

双端数据管理只保留一个资料维护入口，内部分为备份恢复、作者TXT、上传归档三个任务。旧TXT与归档路由进入对应任务。根目录只选择一次，生成 当前/作者资料、当前/备份、上次/作者资料、上次/备份 与上传归档；选择目录、自动与手动导出共用两代完整备份（内容变化时先整代提交为上次再写新当前，数据没变只刷新当前），并生成作者总表TXT、作者资料.md、主表索引及目录说明。目录不额外输出原始片段，资料版呈现当前身份、原文/中文简介、证据、入库记录和关联文件。片段索引限定自动读取的当前片段，旧文件仍保留在磁盘时也不复活已移除片段。

恢复备份及导入TXT继续经过原校验和确认，冲突处理沿用现有流程。Android保留既有SAF备份路径，在切换统一目录前继续可用；统一目录使用已有所有文件访问授权，并原子保存备份与归档的派生位置，自动备份一并更新资料。Web目录属于当前浏览器设备，支持目录授权时保存在IndexedDB并按动作请求授权；未支持时保留文件下载和选择文件导入。Web上传归档保存原件副本，源文件继续由用户管理，单独报告归档失败并保留媒体入库结果。

作者管理提供加入较早/加入较晚两种排序。清单作者沿服务端txtOrder，未入清单者按记录创建时间及ID稳定排列，倒序分别反转清单及记录时间组，未入清单及未知时间仍置后。资料页区分清单序号、记录入库时间与未知历史日期。Android作品详情的作者弹窗复用认证离线头像，按作者、服务域和请求代次隔离图片，Web沿用作者头像组件。

所有共享媒体网格在拖动与惯性滚动中继续请求进入视口的缩略图，移除相册/收藏/历史的分散暂停开关。推荐、COS、排行榜、搜索、作者作品与其他网格统一沿滚动方向预取邻近最多2×列数项（上限16），全应用机会性预取限2并发；跳过组头及动图原件，复用Coil缓存。目标窗口变化或离开页面取消在途预取，窗口失焦暂停，现有分页和后台预取预算保持。

Android本机模式选择统一根目录时，以master镜像模式绑定作者资料/作者总表.txt，先导入TXT再选目录及以后更换目录都将当前作者和实际关联写到新位置。原目录文件保留。远程连接不把手机路径写给远端。偏好提交失败会恢复先前镜像配置，补偿失败与原错误一并保留。主表摘要识别尚未导入的外部编辑，自动写回暂停并提示先导入；确认导入后的原文可由服务端片段识别，继续合成主表。

目录备份继续使用v2，作者主表和完整备份各保留「当前」「上次」两代及各自独立摘要，目录卡与操作反馈统一说明两代共用；恢复入口只有当前/上次，迁移期旧上上次文件用「选择备份文件导入恢复」读取。确认导入前保存本机状态并纳入同一两代轮换，失败停止导入，成功后刷新当前代。每代摘要不符、缺摘要或文件不可读时停止写回并保留现场，自动写回暂停等用户核对；旧三代同目录文件不自动删除，只在目录卡提示清单。现有作者资料差异在迁移提示中汇总。Web失去目录授权或自动写回失败显示在维护根目录卡，可重新选目录授权。

资料维护页面采用紧凑目录摘要、三枚独立分段按钮与任务卡片。目录已连接后仅显示摘要，完整路径与目录选项按需展开；主动作集中在备份卡。备份导出/导入并排，自动备份精简为开关与完成时间，额外同步工具和恢复须知折叠。作者主表提供目录导入与外部TXT选择，来源移除/重建及镜像维护放入高级折叠区，移除需确认。原件归档采用状态卡与上传入口，完整路径独立展开，保留灰底白卡及深色层次。

详情推荐换批在请求结束后归位，即使新旧响应被查询缓存结构共享为同一对象也重新归位，避免键盘滚动延续覆盖先前复位。
