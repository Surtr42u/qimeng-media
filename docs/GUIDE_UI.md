# GUIDE_UI - 当前 UI 维护约束

> 本文整理本仓已记录的现行交互约束与定位，作为日常 UI 维护入口。业务语义由 [领域专题](DOMAIN_RULES.md)定义，接口由 OpenAPI 定义，视觉与本端契约由模块 README 定义。旧仓 GUIDE_UI 是历史来源，不再是必须可访问的外部唯一规格书。
> 本文不宣称完整复刻旧版所有页面；未写明的交互先核对用户要求、相关测试及实现，再补充有效约束，不把历史推测成当前需求。

## 共同约束

- UI 只呈现状态和触发客户端逻辑层动作，不直调 API、不复算推荐/统计/匹配。
- 加载、空态、失败、重试、未保存离开和重复提交防护按所在流程核对；多步保存按成功步骤记账，失败可重试。
- 原件查看保持原始字节与直链；缩略图是独立预览，缓存身份及数据新鲜度按领域/API 专题。
- 常规/COS 分区、同维 OR/跨维 AND、收藏与历史默认范围按 [筛选](domain/filtering.md)、[作者隔离](domain/authors.md)及 API browse，不在组件复制规则。
- 资产编辑负责作者关联/来源维护；来源=获取渠道，与作品出处不同。作者管理保留媒体文件，COS 作者由目录扫描管理。

- 备份仅接收本项目当前v2；选旧v1/缺版本/未知版本时明确拒绝，缺viewEvents数组不发请求。两端确认摘要按原生事件数，不把聚合统计当事件回放；提示按事件身份/关联规则合并、不删除媒体原件，不笼统承诺全部元数据只增不减。

## Web/PWA

定位：[web/README](../web/README.md)。React 页面经 hooks 获取数据；Aurora Glass 的 token/主题/降级、zoom 补偿只在该 README 维护。

- 侧栏返回以首页为终点，到首页后停用；只后退到当前壳内确认过的历史条目，直达子页、刷新或未知历史回落首页，不能退到站外。仍经路由处理未保存离开确认；浏览器自身后退行为不改。
- 数据管理入口卡保留左侧语义图标和整卡链接，不显示右上角跳转箭头。

- 数据页窗口联动总浏览/播放/停留、浏览占比及统计作者/标签榜；静图/动图/视频互斥，榜单沿用入口窗口与服务端排序。错误单独显示并可重试，有限榜单不标为全量；统计语义与 Android 同源。
- 数据页与“我的”沿用维护页的Aurora Glass卡片/标题/紫青色，统计活动与当前库存明确分区。数据窗口保存在range参数，完整榜单沿用窗口；各板块独立加载/失败/重试，旧协议仍明确提示升级，不因单一榜单失败遮住全页。窗口覆盖数量直接展示服务端viewedFilesCount/viewedAuthorsCount/viewedTagsCount，不以Top5或平均数反推。
- 数据页内容榜保留封面在上、标题在下的大封面卡片样式：宽卡三列、窄卡两列、极窄卡单列，Top5及服务端顺序不变。封面仍为16:9，标题最多两行，取消额外第二行占位并微调间距；不改为横向小封面榜单或增加序号，不强制与右侧占比卡等高。
- 数据页底部三张榜单卡采用一致的紧凑单行高度；标题、说明及同序分隔线横向对齐。作者总览每行只显示作者名，不再显示文件数副标题；顶部作者总数/关注数、原排序及跳转保留。
- “我的”保留关注/收藏/历史及原分页、收藏时间排序和常规/COS默认范围；分区tab与历史筛选q保存在URL并替换当前条目，返回恢复原分区。Tab支持左右/Home/End，榜单与历史卡支持键盘打开；取消关注失败保留列表并提示，失败不误报为空。历史筛选明确只查已加载文件名，匹配数与已加载数分开显示，不用“共N项到底了”冒充筛选结果；筛选期间停止自动续页并提供加载更多，非筛选仍自动续页，错误可单独重试。个人概况不虚构管理员身份，未知库存显示缺省而非零。
- 浏览历史条目沿用首页媒体流的无外框排版，仅封面保留圆角；浏览时间、观看进度、来源信息、键盘打开及分组分页行为保留。
- 首页推荐/COS在内容上方常驻“换一批”，热榜对应“刷新榜单”；仍复用原seed/刷新键与分页，不计算客户端排序。摘要只显示已加载条数，换批期间显示更新中，不将其写成全库数量。
- 相册标题展示服务端匹配数与已加载数，提供一键清空所有维度和高级筛选；维度选项可独立展开/收起，已生效筛选不强制撑开。首次读取失败在顶部提示，续页失败的重试入口放在已有列表末尾；均保留已有条目，不显示误导性的空相册提示。
- 首页/相册等共享媒体卡支持Tab聚焦及Enter/空格打开，名称与焦点环明确；鼠标打开与原批次详情导航保留。
- 上传工作台支持目录拖拽和队列，直传/分片分流及刷新恢复按 API files；作者编辑在资产编辑页。
- 上传内部把位置设置、可选作者来源、添加入口和任务结果分区；目录按需展开，作者来源折叠不清值，添加区常显本批摘要。尚未确认已有作者身份的回车结果须选定或清空后才能新入队；不把自由文字显示成已完成关联。任务卡展示入队快照及完整错误，窄窗口不依赖横向六列表格，清理已结束记录不删除媒体；仍选入即上传，不恢复暂存/开始上传步骤。
- 上传队列持久化初始化/读取/写入失败显示页面有效性与刷新风险；删除旧记录失败单独提示核对已入库文件。重试按钮只重试本地存储，保持传输与成功/挂靠事实，不自动重传。恢复跳过持久化终态标记，双重存储故障仍可能留下旧记录；uploadId 七天凭据边界不变。
- 刷新后重选上传文件时核对名称、大小及已有修改时间；不匹配留在待选状态并显示原因，防止把改写过的文件接到旧任务上。
- 详情展示、播放、时间轴、相册与管理页共享现行业务口径；库变更、成功备份导入及 SSE 重连会刷新统计/排行/历史等缓存，持续挂载页面不依赖重进刷新。SSE 机制查 API browse。
- 视频详情播放器不再显示左上角“已看完”角标；完成判定、从头重播/断点续播和进度上报不变，浏览历史列表的完成徽标保留。
- ConfirmDialog 的 busy/失败重试、路由拦截与 beforeunload 的未保存保护是现行交互防线。
- 设置页的界面/推荐偏好按内容宽度并排，窄区自动上下排列；清晰度与推荐预设用按文字宽度排列的紧凑按钮，不拉伸为整行。即时保存与原偏好语义保留。
- 设置保存期间允许继续编辑；响应只确认提交时的修订，后续草稿与失败草稿保留，初次查询/刷新不能覆盖输入。扫描参数仍为预留，重启也不生效。
- 当前不展示快照调度卡；快照 API 能力仍在，不据旧截图/历史重建该 UI。
- 维护页采用紧凑仪表盘，保留既有紫青/玻璃美术。流量卡含趋势/峰值/累计/采样点提示，重复的独立网络大图已撤下；文件管理、回收站与上传仍跳转原路由，异常快捷入口定位常驻日志，最近5条/展开全部保持。服务器目录自动导入移到上传页高级入口，明确无人值守匹配及成功移走源文件，不与逐批作者/来源上传混淆；触发/失败/忽略/最近成功能力保留，折叠停定时轮询，后端通道未退役。监控/日志失败可重试并保留旧记录，缺失读数不伪零；按内容区宽度适配。
- 数据管理按任务分组，上传新文件与整理已有文件分开；整理页支持游标续页，批量只对已加载选集操作。换库/目录等待新列表，不把旧目录文件套上新目录动作；错误与空目录区分，键盘/触屏可用文件操作。上传仅向已知启用的目标入队，配置失败/暂停接收时阻止新任务；队列既有目标不受后续修改影响。作者挂靠按服务端能力，换作者清空批次来源。
- 库注册与扫描分步反馈，第二步失败保留已注册事实并提供单独重试；扫描受理不等于完成。停用前说明文件/记录保留，移除登记前说明收藏/标签/作者等关联影响；失败保留确认框。来源词表/镜像读取失败不开放保存，保存期间锁编辑、失败留草稿，来源/镜像共用未保存离开保护并可放弃修改；TXT/备份读取防重入，移除TXT片段先确认重建影响，冲突处理及v2限制保持。

## Android

导航/详情/播放器/上传的职责定位见 [Android 维护入口](../android/README.md#维护定位)；状态与生命周期仍各自单源，内部拆分不改变下列现行交互。

定位：[android/README](../android/README.md)。Compose → ViewModel → Repository，feature → core。地址经 ServerConfigDataSource，在线/本机模式共用 UI 与协议。

- 常驻层与跳板路由隔离 Tab 状态；悬浮胶囊底栏的空白区域消费触摸，避免穿透媒体卡片。
- 首页默认推荐与 COS 都由服务端推荐，COS 只取 COS 子集；下拉换 seed 重排，不用“已是最新”解释推荐换批。COS 显式筛选/排序时保留资产列表行为，重置筛选回推荐模式。小库或评分约束下换 seed 仍可能同序，不承诺每次内容必不同。
- 数据统计主/详情页读取服务端窗口汇总、互斥类型数量及未截断文件/作者/标签数，趋势所有类型/来源共用一次响应日期轴；失败为独立错误态并支持同档重试，不显示伪零值。
- 数据统计主页及详情的浏览趋势图不绘制背景网格线，保留折线、面积、数据点、日期标签和点选气泡；权威统计口径见 [统计专题](domain/statistics.md)。
- 搜索入口/建议/结果三态；结果区固定媒体类型（综合/视频/动图/图片）与分区（全部/常规/COS）两级选项。切换选项回顶，换词重置默认档位；映射仍按领域/API。
- 首页/搜索/库管理的挂起业务调用继续传播取消，不弹失败或启动普通失败重试；loading 只由当前请求释放。返回搜索入口即作废在途结果，注册成功与后续扫描分别记账。
- 作者 TXT 选择后由数据层先检查扩展名/声明大小，再有界读取并核对 JSON 请求字节（含转义），超限不出网；读取期间禁重入，失败可重新选择。限制见 [作者 API](api/authors.md)。
- 上传入口为系统文件 SAF 与系统分享，后台 WorkManager；可配置归档文件夹及按库名一键上传。归档一键上传的说明/确认框明确：PC/NAS 确认入库后删除已上传的手机归档副本，本机上传保留；清理失败或文件变化时保留，在成功队列行与通知显示提示，不触发重传。单任务取消在持久化成功后展示“已取消”，失败明确提示重试；不级联取消后续队列。暂存区/收件箱旧流程已退役，不照历史恢复。
- 本机词表维护与两端词表同步为并集合并（ADR-0035）；旧单向覆盖方案仅历史参考。词表维护页保存成功后有静默回读（抹平服务端规范化差异）；初次加载或保存后回读期间的新草稿均受修订号保护，较慢旧响应不能覆盖。保存态先结束再发起回读，即时完成的规范化结果也能回填；回读期间可继续编辑，已保存结果与提示不因回读失败/取消变更为失败。
- 播放/图片复杂自绘 View 可经 AndroidView 桥接（ADR-0014 例外），使用时记交付清单；禁止搬旧 Kotlin 页面实现。

- 当前视觉与已取消布局方案的有效边界统一查 [Android README](../android/README.md#构建与设备验证)；试调经过查 [背景对比度记录](ANDROID_UI_TASKBOOK.md)，不在交互指南复制视觉参数。

## 桌面

定位：[desktop/README](../desktop/README.md)。Tauri 连接壳加载服务端同一 Web UI，当前播放器是 ArtPlayer，ADR-0036 libmpv 路线已废弃。

修改 Web TopBar 必须核对 desktop README 的 titlebar.js 动作属性与旧版兼容契约；设置窗、托盘、导航守卫及窗口行为由桌面端维护，不要求所有 Web 样式任务读取整个桌面实现。

## 验证与维护

只改视觉时核对 token/主题与受影响页面；交互变化覆盖加载/失败/重试/返回等相关路径，业务规则变化另同步领域专题。Android 显式目标与隔离真库纪律见 AGENTS。新交互直接更新本节，不追加覆盖旧正文的修订补丁；重大架构改变另写 ADR。
