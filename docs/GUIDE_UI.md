# GUIDE_UI - 当前 UI 维护约束

> 本文整理本仓已记录的现行交互约束与定位，作为日常 UI 维护入口。业务语义由 [领域专题](DOMAIN_RULES.md)定义，接口由 OpenAPI 定义，视觉与本端契约由模块 README 定义。旧仓 GUIDE_UI 是历史来源，不再是必须可访问的外部唯一规格书。
> 本文不宣称完整复刻旧版所有页面；未写明的交互先核对用户要求、相关测试及实现，再补充有效约束，不把历史推测成当前需求。

## 共同约束

- UI 只呈现状态和触发客户端逻辑层动作，不直调 API、不复算推荐/统计/匹配。
- 加载、空态、失败、重试、未保存离开和重复提交防护按所在流程核对；多步保存按成功步骤记账，失败可重试。
- 原件查看保持原始字节与直链；缩略图是独立预览，缓存身份及数据新鲜度按领域/API 专题。
- 常规/COS 分区、同维 OR/跨维 AND、收藏与历史默认范围按 [筛选](domain/filtering.md)、[作者隔离](domain/authors.md)及 API browse，不在组件复制规则。
- 资产编辑负责作者关联/来源维护；来源=获取渠道，与作品出处不同。作者管理保留媒体文件，COS 作者由目录扫描管理。

## Web/PWA

定位：[web/README](../web/README.md)。React 页面经 hooks 获取数据；Aurora Glass 的 token/主题/降级、zoom 补偿只在该 README 维护。

- 上传工作台支持目录拖拽和队列，直传/分片分流及刷新恢复按 API files；作者编辑在资产编辑页。
- 详情展示、播放、时间轴、相册与管理页共享现行业务口径；SSE 失效及重连对齐查 API browse。
- ConfirmDialog 的 busy/失败重试、路由拦截与 beforeunload 的未保存保护是现行交互防线。
- 当前不展示快照调度卡；快照 API 能力仍在，不据旧截图/历史重建该 UI。

## Android

定位：[android/README](../android/README.md)。Compose → ViewModel → Repository，feature → core。地址经 ServerConfigDataSource，在线/本机模式共用 UI 与协议。

- 常驻层与跳板路由隔离 Tab 状态；悬浮胶囊底栏的空白区域消费触摸，避免穿透媒体卡片。
- 搜索入口/建议/结果三态；结果区固定媒体类型（综合/视频/动图/图片）与分区（全部/常规/COS）两级选项。切换选项回顶，换词重置默认档位；映射仍按领域/API。
- 上传入口为系统文件 SAF 与系统分享，后台 WorkManager；可配置归档文件夹及按库名一键上传。暂存区/收件箱旧流程已退役，不照历史恢复。
- 本机词表维护与两端词表同步为并集合并（ADR-0035）；旧单向覆盖方案仅历史参考。
- 播放/图片复杂自绘 View 可经 AndroidView 桥接（ADR-0014 例外），使用时记交付清单；禁止搬旧 Kotlin 页面实现。

- 当前主题背景与对比度优化已获用户确认，并保留“主体色彩”→“外观”改名。日间整页与内容卡均为 #FFFFFF 纯白，不铺设冷灰/蓝紫渐变；设置/统计首页及详情/管理卡共用 SoftDaylight 的低强度中性阴影，不叠加白高光或有色投影，辅助容器使用中性灰。深色背景/材质保持原值，次级文字对比度提高。系统栏图标跟随 App 实际主题。首页搜索、筛选、列数入口、推荐/COS/排行榜三胶囊及相册维度/值胶囊保持原玻璃配色，仅复用内容卡的中性柔和投影提供轻微浮起感；不加灰色染色或硬描边，原尺寸、间距和按压反馈不变。
- 本轮布局改造已按用户要求撤回：首页、相册横向预览、筛选面板、外观页结构及导航保持原交互。试调范围与验证见 [Android 背景对比度记录](ANDROID_UI_TASKBOOK.md)。

## 桌面

定位：[desktop/README](../desktop/README.md)。Tauri 连接壳加载服务端同一 Web UI，当前播放器是 ArtPlayer，ADR-0036 libmpv 路线已废弃。

修改 Web TopBar 必须核对 desktop README 的 titlebar.js 类名/title/header 契约；设置窗、托盘、导航守卫及窗口行为由桌面端维护，不要求所有 Web 样式任务读取整个桌面实现。

## 验证与维护

只改视觉时核对 token/主题与受影响页面；交互变化覆盖加载/失败/重试/返回等相关路径，业务规则变化另同步领域专题。Android 显式目标与隔离真库纪律见 AGENTS。新交互直接更新本节，不追加覆盖旧正文的修订补丁；重大架构改变另写 ADR。
