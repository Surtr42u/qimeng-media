# 标签/收藏/点赞/时间轴

> 本专题是领域规则正文；[领域目录](../DOMAIN_RULES.md)保留原 §编号。公式与常量保持原义，标记「逐字遵守」者未经用户明确要求不得改变。

## 7. 标签/收藏/点赞/时间轴

- 标签：全局池 + 文件多对多；模糊/精确两种筛选模式；浏览中新标签自动入池；删除标签清理全部关联（级联）。
- 标签**不写入媒体文件**（元数据只在库内）。
- **标签排序**：标签列表（GET /tags，筛选面板等非详情场景）按**名称升序**返回；资产详情页 tags 按**关联时间倒序**（最新添加置顶）——PUT /assets/{id}/tags 为整体替换，每次替换即刷新全部关联时间（替换即置顶，重添加天然置顶）；同批毫秒内按标签创建时间倒序 tie-break。**逐条解除**（DELETE /assets/{id}/tags/{tag}，2026-09-09 协议批 P2 新增）：只删该条关联，**其余关联的 created_at 一律不动**（旧版「chip 关闭即时移除单条」语义，不触发整体替换的时间刷新）；幂等 = 标签存在但未挂载 → 204，资产不存在或标签池无此名 → 404。
- 收藏：布尔标记集合。
- 关注：作者维度的布尔标记（对象是作者而非文件），语义见 §6「关注作者」；与收藏同为无次数布尔量（§5）。
- 点赞：见 §5；排行榜热度含点赞数。
- 时间轴标签：视频内时间点标记（assetId + 毫秒 + 名称），与文件标签完全独立的体系；点击跳转回看。**颜色协议化**（2026-09-09 协议批 P2）：标签对象增可选 `color`（hex 6 位，如 `#d6336c`），创建/更新/响应三处透传；缺省 = 服务端不存颜色、客户端自兜底；**预设类型不入协议**（客户端按 color 自持）。
