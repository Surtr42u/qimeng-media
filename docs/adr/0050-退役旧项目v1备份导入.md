# ADR-0050：退役旧项目v1备份导入

## 背景（Context）

用户已停用另一个纯本地项目，只使用本项目App/Web，并要求精简旧数据兼容。当前备份为v2，原生事件身份已能跨实例守恒；v1仍维护聚合造事件、批次锚与猜取最早同名资产的独立路径。

## 决策（Decision）

仅接收schemaVersion=2，其他版本在任何写入前400；Web/Android选择旧文件时明确拒绝。删除v1聚合回放、批次标记和旧文件匹配路径。保留v2导入导出、作者/TXT/标签/收藏/偏好、事件去重与统计重建；现有v2信封字段/类型名不改，展示用聚合段不再作为导入事件源。

## 状态（Status）

Accepted（2026-10-25，用户要求精简已停用旧App兼容）。部分取代ADR-0040中“v1保持原回放边界”；其余v2身份、统计与缓存决策继续有效。

## 后果（Consequences）

旧项目v1文件不能再导入，不自动转换；已入库历史和legacy/无键事件身份保留，历史migration不改、真库不清理。联动api/openapi.yaml、sdk.lock、portablebackup、两端备份校验/提示与回归、domain/migration、api/backup、模块README、HANDOVER/能力地图；旧映射归档到history/LEGACY_BACKUP_V1.md。当前安装包不因源码改动自动替换。
