# ADR-0045：推荐打散限制桶内分差

日期：2026-10-20。

## 背景（Context）

用户要求评估并优化推荐、编译装机。现有分桶每次比较相邻分数，1.00、0.96、0.92 等可链式并入同桶，导致高低分一起打散，削弱评分；已有测试只覆盖明显断层。

## 决策（Decision）

- seed>0 时以桶首最高分为锚，落后不超过 0.05（含边界）才同桶；桶间保持降序后再做既定类型混合。用连续分差与精确边界回归，而非只测大断层。
- 固定评分、权重、每日惩罚、随机哈希、媒体混合及缓存不变；每项完整标签只构建一次，连续切片洗牌，单类型跳过混合缓冲。
- 缺乏真实反馈对照，暂不重调偏好权重；明确作者/出处去重尚未实现。评估基准不能代替推荐质量或手机延迟证明。

## 状态（Status）

Accepted；分桶语义修正，自动化通过。

## 后果（Consequences）

刷新顺序会改变；同输入/时间/seed 仍可复现。影响 server/internal/recommend；现行规则与测量在 [推荐专题](../domain/recommendation.md)，同步 API 行为说明、能力地图/交接和 Android 装机范围。
