# ADR-0034：App 词表同步——远端词表单向下发覆盖本机内嵌库

## 背景（Context）

检索词表数据层（kv_settings.custom_source_groups / custom_stop_words）存于**各部署
自己的库**：电脑端经 ADR-0033 端点补的词条（D.Mon 改名、怪物猎人/战锤40k 新组、
停用词），手机本地库永远拿不到。内嵌形态的词表端点受一次性共享密钥保护（2026-09-30
批A 防同机越权，密钥只在 App 内存），外部不可写——「拿不到」与「写不进」双向封死。
ADR-0033 补记三的固化（130→133 组）是一次性止血：每次词条变更都固化基线要重编译
三端服务端，且固化后历史部署仍各自漂移。用户拍板「为什么不和电脑一致」，把
0033 补记三遗留的「App 端词表同步」提案转为实施。

约束：服务端/openapi/SDK 零改动（GET/PUT /sources/custom-groups 两端点与三端 SDK
方法均已存在，直接消费）；App 在远程登录态下执行（本机模式没有权威源）；内嵌形态
服务端是 jniLibs `.so` 子进程（exec nativeLibraryDir），随按需拉起的 Service 生命周期。

## 决策（Decision）

1. **服务端（NAS/电脑端）为唯一权威源，单向下发**：App 处于远程登录态时，把该端
   词表（自定义出处组 + 停用词）拉取后覆盖写入本机内嵌库。本机模式下入口提示
   「单机模式无权威词表源，请先登录 NAS/电脑端」，不发起任何请求。
2. **纯客户端编排，协议零改动**：远端 `GET /sources/custom-groups`（标准鉴权）→
   拉起内嵌服务端（ensureStartedIfLocalMode + LocalServerWarmup 端口就绪等待，
   AuthRepositoryImpl 登录链同款先例）→ 本地 dev-login（密钥内存槽现取）→ 本地
   `GET`（预览对照）/ `PUT`（覆盖下发）。UI 零业务规则，编排全在 core:data
   VocabularySyncRepository。
3. **本地通道独立无拦截器客户端**（NetworkModule `@LocalDirectClient`）：对
   127.0.0.1:18430 的 dev-login/GET/PUT 走全新 OkHttp（**不挂 AuthInterceptor**）——
   全局客户端的 401 处理是 clearToken+登出广播，本地请求若误用会把用户的 NAS 会话
   踢回登录页（本决策最大陷阱）。本地 Bearer 经 SDK 生成物实例级
   accessTokenProvider 注入，与全局 ServerConfig token 两套会话互不接触。
4. **同步显式覆盖 groups + stopWords**：PUT body 恒显式携带两字段——groups 整体
   替换语义天然覆盖；stopWords 恒传**显式数组**（远端无追加层时传空数组=清空），
   不用协议缺省语义（缺省=保持现值），保证同步后「本机=远端」而非「保留现值」。
   PUT 成功即完成信号：服务端自动同步替换引擎并后台全常规库重算，无需依赖 SSE。
5. **两段式交互 + 本机独有确认防线**：预览面板先示「远端 N 组 / 本机 M 组 / 本机
   独有 K 组（同步后丢失）」（本机 canonical 不在远端，trim+忽略大小写对齐引擎折叠
   口径；独有行 >0 以警示色强调），确认后才执行 PUT；内嵌服务端按需拉起、操作收尾
   停回（恢复壳层「主键非本机预设=停服」不变量）。

被否决的替代：**双向合并**（两端词条冲突语义——谁赢、删了怎么回来的裁决不值当，
单向「以服务端为准」一句话说清）；**App 端词表编辑 UI**（本机词表的直接维护面，
待提案记档，本决策不排除）；**服务端新增批量同步端点**（两端点已够，零收益）。

## 状态（Status）

已接受（2026-10-04）

## 后果（Consequences）

- 受影响文件（全部为 App 端，服务端/openapi/SDK 零改动）：`android/core/network/`（NetworkModule
  的 @LocalDirectClient 客户端/DefaultApi/AuthApi 三装配）、`android/core/data/`
  （VocabularySyncRepository 接口+Impl、DataModule @Binds）、`android/feature/manage/`
  （VocabularySyncViewModel/Screen 新子页、DataManageScreen 入口行）、`android/app/`
  （QimengNavHost 路由）、`docs/`（本 ADR、INDEX、GUIDE_API、HANDOVER、CHANGELOG）。
- 已知限制：①覆盖式下发，本机独有词条/停用词同步后丢失（预览明示数量+确认防线，
  用户拍板的语义而非缺陷）；②dev-login 在本机 auth_sessions 留会话行，随会话过期
  策略消亡，无实害；③同步中途用户换端（极罕见）以门禁与守卫兜底——执行前重校验、
  收尾停服前复查主键；④本机通道只认内嵌预设地址，自定义端口 Termux 形态 A 不在
  本功能语义内。
- 词表变更的存量传导复用 ADR-0033 闭环（PUT → 引擎同步替换 → 后台重算 →
  library.changed），DOMAIN_RULES §4 口径不变。
- 远程登录态期间内嵌服务端短暂拉起（预览与执行各自独立拉起/回收），会产生瞬时的
  前台服务通知——与既有「本机模式才常驻」的观感不同，属按需工具化的既定代价。
