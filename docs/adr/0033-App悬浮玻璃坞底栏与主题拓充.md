# ADR-0033：App 悬浮玻璃坞底栏与主题拓充——单库玻璃材质（Kyant0 Backdrop）+ 四材质方案 + 外观三态

## 背景（Context）

未合并分支 ui/app-redesign（2026-10-02 评审期「流光玻璃」雏形）验证了玻璃坞底栏 + 日间玻璃配色的方向，但有三处硬伤：①选中指示=每个导航项各持一颗胶囊做 scale+alpha spring 交叉淡化，两颗 spring 相位独立、过冲/欠冲叠加，用户感知「胶囊移动时左右空隙不一致」；②胶囊宽写死 46dp 与槽位零关联，端部槽位与全圆坞壁之间的空隙天然只有中段相邻空隙的一半（密度观感不均）；③所谓玻璃实为半透明填充+受光描边的降级形态，无真实背景模糊。主线（master）底栏为标准 M3 `NavigationBar`（无动效），夜间为旧中性灰板（用户评价「太差」，明确要求按新 UI 重做）。

用户 2026-10-03 夜间批次拍板：把分支日间视觉提取到主线重做，底栏重做为「独立悬浮层 + 液态玻璃/磨砂玻璃双真材质」，拓充主题模式（官方/开源/主流多方案），选项卡动效与阴影立体感做足，夜间模式按新 UI 重做；全部验证走云端 CI（夜间纪律），不碰主分支。

## 决策（Decision）

**1. 悬浮玻璃坞独立层**：底栏脱离 Scaffold bottomBar 顶升模型，改为内容区之上的覆盖层（Box BottomCenter + zIndex）。内容区 bottom 不再被钉位——延伸到屏底、从坞身后滚过，四个常驻 Tab 页滚动容器以单源让位常量（`TabDockDefaults.bottomClearance`）留白。AuroraBackdrop 极光画布铺壳层底（仅玻璃档渲染）作玻璃色彩基底，与 Web 端 Aurora Glass（ADR-0031）的「画布层供模糊基底」同构。

**2. 单颗滑动指示胶囊**：坞层只持一颗胶囊，按槽位中心偏移（`selectedIndex × slotWidth + slotWidth/2`，slotWidth 由 `onSizeChanged` 实测）spring 滑动；胶囊宽 = 槽宽 − 2×槽内边距（派生，非写死）；Row 首尾内边距 = 槽内边距，使「端部空隙 = 中段相邻空隙」按构造成立。位移 spring 的过冲安全（只改位置不改胶囊尺寸，正是「液态」滑动语感），弹跳微交互只留给图标点亮（1.12×）。三根因（相位独立的交叉淡化/写死宽度/端部密度差）一并根治。

**3. 玻璃材质 = 单库家族 Kyant0 Backdrop 2.0.1**（`io.github.kyant0:backdrop`，代码包名 `com.kyant.backdrop`，Apache-2.0，Maven Central 2026-10-03 实查可解析，传递依赖 `io.github.kyant0:shapes`；仅 core:ui 消费）：液态=官方 Glass Bottom Bar 配方（`vibrancy` + `blur` + `lens` 折射 + 表面高光），磨砂=`blur(22dp)`（与 Web 端 Aurora Glass `backdrop-filter: blur(22px)` 同源对齐）+ 高遮盖 scrim + 发丝描边。两档共用同一条背景捕获管线（一次 capture，差异只在 effects 配置），运行时只激活一条管线。选型四问记档：①业界通行=Haze（chrisbanes）与 Backdrop（Kyant0）双雄；②不用 Haze 的可证伪理由=Haze 1.x 无折射能力（液态只能靠 2.0 实验性 haze-glass，2.x 线自述 beta 且 API 全换代），Backdrop 有官方玻璃底栏教程且一库同时覆盖液态+磨砂（单管线零双捕);③复查条件=Backdrop 停维护/API 破坏性变更/实测性能不达标→切 Haze 1.7.3（磨砂）+伪液态降级；④退役触发=Compose 官方提供 backdrop 原语且普及（如 `RenderNode.setBackdropRenderEffect` 下放）后整件替换。

**4. 材质方案四档（拓充主题模式）**：LIQUID 液态玻璃（默认）/ FROSTED 磨砂玻璃 / SOLID 纯色 M3 官方坞（零捕获零模糊，性能与兼容档）/ CLASSIC 经典（主线改前 M3 NavigationBar 悬浮化，保底回退档）。API 降级链收敛单点 `resolveBackdropCapabilities`：API ≥33 全量（blur+vibrancy+lens）；31–32 去 lens（RenderEffect 有、AGSL 无）；≤30 伪玻璃（半透明面+发丝描边+顶缘高光+阴影，即分支 GlassSurface 观感，替代 Backdrop 的静默无效果）。

**5. 主题模式拓充**：外观模式三态手动开关（跟随系统/浅色/深色）+ 底栏材质四选 + 主题色彩六档（极光=默认鸢尾系观感零变化/青碧/琥珀/绯樱/苍翠五套预设 + 动态取色=Material You 官方 `dynamicColorScheme`，API<31 回落极光基座），经既有 ClientPrefs DataStore 模式持久化；MainActivity 单点解析 darkTheme（全 App 唯一暗色判定点），AuroraBackdrop/GlassColors 经 `isQimengDarkTheme` 与 Theme 同源（禁双源）；中性面共用基座不随预设变（动态取色档是官方语义例外，连中性面随壁纸）；极光氛围辉光前两色派生自 colorScheme.primary/tertiary 随预设换相（有意决策，后两色固定）。**推翻 App 流光玻璃 ADR（ui/app-redesign 版 0031）「不新增主题开关」约束**——用户 2026-10-03 明确要求拓充主题模式，用户最新要求优先。夜间配色=分支暗色极光板（旧灰板退役；`PrimarySoftLight/Dark` 保留为兼容别名，仅 CLASSIC 指示器消费，新代码禁用）。

**6. 机制红线**：`resolveTabTapAction` 双击回顶/防抖、`visitedTabs/currentTabRoute/stateHolder` 常驻层、tab 转场 `fadeIn(snap())/fadeOut(snap())`（防叠影）逐字保留，只换视觉容器；feature 层禁止 import glass 包颜色（只走 MaterialTheme token）；不提取分支预览变体脚手架（`-PqmPreviewAurora` 端口注入/18431/CI 预览步，其 ADR 自定合并期退役）。

## 状态（Status）

Accepted（2026-10-03，用户夜间批次拍板；Backdrop 依赖落地按用户「官方库/现成方案优先」指令执行，早间报告向用户追认 ADR-0014 白名单追加项）

## 后果（Consequences）

- 正面：底栏获得真实液态/磨砂玻璃质感与内容穿透滚动；胶囊空隙不均按构造根治；主题可选面拓至 4 材质 × 3 外观；夜间换新极光暗板。
- 代价/风险：新增 Android 运行时依赖（ADR-0014 白名单追加，待用户追认）；Backdrop 2.0.1 与其文档主线存在版本差（只消费教程四参调用面降险，CI 编译为第一验证点）；玻璃模糊在 API 26–30 降级为伪玻璃（`qimeng_api35` 模拟器为 API 35 全量效果）；主壳 QimengNavHost 已超 600 行警戒线（改前即超，本批再加约 118 行，注释记档、拆分另立批次）；被提取的 GlassCard/GlassIconButton/pressScale 等暂无消费方（玻璃语言库件，待后续批次接线）。
- 受影响文件：`android/gradle/libs.versions.toml`、`android/core/{model,ui,data}/`、`android/app/`（MainActivity/QimengNavHost/session）、`android/feature/{home,all,stats,settings}/`、`docs/adr/INDEX.md`、`docs/CHANGELOG.md`。
