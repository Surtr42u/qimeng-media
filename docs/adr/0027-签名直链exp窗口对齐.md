# ADR-0027：签名直链 exp 窗口对齐（同窗 URL 恒定，根治逐响应轮换击穿 HTTP 缓存）

## 背景（Context）

服务端对每个列表/详情响应把全部媒体 URL 重新签名（`exp = now + TTL`，精确到秒），同一资产同一尺寸的 URL 字符串随每次响应变化。后果沿两端分别发酵：

- **Web 端零补偿**：浏览器 HTTP 缓存按完整 URL 做键，URL 每次都变 → `/media/**` 缓存永久不命中，每次列表刷新/详情重看全量重下；服务端早已实现的 ETag/If-None-Match（`server/internal/httpapi/media.go`）因缓存键不存在而永远走不到 304。
- **Android 端被迫自建「剥签名键栈」**：`SignedMediaCacheKeys` 剥 exp/sig 得稳定键、`SplitDiskCache` 分池、`PrefetchDiskProbe` 探测——历史上已引发三轮真实 bug（CHANGELOG 第二百六十六笔、第三百六十五笔、第四百一十一笔），维护成本持续外溢。

根因单一：**exp 逐响应轮换**。约束：签名直链协议（`/media/**?exp=&sig=`，auth 包 `SignMediaURL`/`VerifyMediaSignature`）是稳定协议，签名消息格式与验签逻辑一个字节都不能动；吊销语义（删除 media-secret 换密钥 = 吊销全部存量直链）必须保持。

## 决策（Decision）

采用 S3/CloudFront 签名 URL 的「窗口取整」同款思路：**exp 不再是 now+TTL，而是「下一个窗口上界 + 一个 TTL」**（`server/internal/httpapi/assets_media_url.go` 的 `mediaURLExpiry` 纯函数）：

1. **exp = (now + TTL).Truncate(TTL) + TTL**，窗长与直链有效期同值（`token_ttl`，缺省 `DefaultTokenTTL`=6h，对齐 Unix 纪元整点）——同一时间窗内所有响应生成**逐字节相同**的 URL，浏览器缓存与 ETag/304 自然生效。一个旋钮控制两件事：URL 每日至多轮换 4 次。
2. **有效期恒 ∈ (TTL, 2×TTL]**：最短仍是一个完整 TTL，绝不出现「取到即近过期」的 URL。
3. **验签侧零改动**：exp 仍是绝对 Unix 秒时间戳，只改签发值的取法；签名消息构造（`path+"\n"+exp`）与校验顺序原样。
4. **`/media/orig/**` 补 `Cache-Control: private, max-age=<窗口秒数>`**（max-age 取实际生效 ttl）：此前该端点完全无缓存头；URL 恒定后显式 max-age 才有意义，且缓存条目寿命不可能超过 URL 有效期下界。缩略图直链既有 immutable 长缓存（内容寻址键）不动。
5. **Android 剥签名键栈保留，明确「不退役」**：窗口轮换下若改用全 URL 缓存键，每日 4 次轮换仍会造成全量失键重下；剥 exp/sig 的稳定键严格更优（键不含 exp 值，对 exp 取值规律天然无感）。三端（web/android/desktop）零适配。
6. **刻意不做**：a) 纯窗口上界不叠加 TTL——窗口尾签出的 URL 几分钟内过期，被本 ADR 否决（决策 2 的下界即为此设）；b) 长寿命/免签直链——扩大泄露直链的存活窗与攻击面，安全否决（SECURITY 红线 5 的短期签名语义不变）；c) 窗口边界随机抖动等反缓存技巧——与目标正好相反。

## 状态（Status）

Accepted（2026-10-01）

## 后果（Consequences）

- **积极**：Web 端 `/media/**` HTTP 缓存与 ETag/304 从此真正命中（同窗重复观看零重下）；URL 轮换从「每响应一次」降为「每窗口至多 1 次」；Android 键栈不再需要为 exp 轮换打补丁。
- **代价与风险**：吊销粒度从「请求级过期」粗化为「窗口级」——泄露直链最长可存活约 2×TTL（原为 ≤TTL），总闸不变 = 删除 media-secret 换密钥立即吊销全部存量直链（SECURITY.md「token 泄露应急」语义不变）；部署后旧语义签发的 URL 按其自身 exp 自然过期，过渡无感。
- **联动文件**：`server/internal/httpapi/assets_media_url.go`（mediaURLExpiry + signedMediaURL）、`server/internal/httpapi/media.go`（signedOrigCacheControl）、`server/internal/httpapi/assets_media_url_window_test.go`（新增）、`server/internal/httpapi/browse_test.go`（过期用例时钟前移量适配）、`docs/SECURITY.md`、`docs/GUIDE_API.md`、`docs/HANDOVER.md`、`docs/CHANGELOG.md`（第四百一十四笔）、`docs/adr/INDEX.md`。`api/openapi.yaml` 与三端生成物零改动（URL 格式与参数名未变，仅取值规律变化）。
