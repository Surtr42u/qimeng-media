# ADR-0040：便携事件身份与统计缓存一致性

## 背景（Context）

第二轮 R1–R5 证明聚合备份丢失原始事件身份，统计重建跨快照，缩略图缺内容版本。取最大计数无法合并独立新增事件。

## 决策（Decision）

- 备份 v2 以 viewEvents 原始身份/会话/时间/秒数/日键合并；聚合段仅兼容展示，缺事件段拒绝导入。v1 保持原回放边界。无键历史由 migration 0019 旁表和触发器分配持久身份，不修改事件原文；已有 UUID/legacy 键原样往返。
- recordKey 全局查重、按资产ID稳定消歧；v2 本地ID优先，跨库按文件名/相对路径/库名唯一匹配，歧义及多对一跳过告警。路径是属性，绝对库根不入备份。
- eventstats 编排重建：immediate 事务内读真相并替换；恢复原身份与单资产日统计同事务。stats 仅纯函数聚合。
- 缩略图表示版本贯穿 URL/磁盘键/Android 稳定键，含原件 size+mtime、策略、格式和配置；实际字节哈希为强 ETag。旧版本 URL 返回 410/no-store；无版本 URL 兼容但须重验证。预取同时比较库修订号及策略指纹。

## 状态（Status）

Accepted（2026-10-19，用户授权完成第二轮修复）。v1导入承诺于2026-10-25由[ADR-0050](0050-退役旧项目v1备份导入.md)部分取代；其余v2身份/统计/缓存规则继续有效。

## 后果（Consequences）

需同步升级服务端与客户端；旧客户端可能丢弃 v2 新字段，不能用其转存 v2。相同 size/mtime 的原件篡改仍属 ADR-0004 检测边界；旧版聚合无法补回已丢身份。旧散列缓存成为孤儿待对账，真实 NAS/双卷/掉电未验收。影响 openapi、sdk.lock、migrations/0019、eventstats、stats、thumbnail、httpapi 与 Android core/data；联动 DOMAIN_RULES、GUIDE_API、ARCHITECTURE、HANDOVER、CAPABILITY_MAP。

实现依据：[SQLite 写事务与快照](https://www.sqlite.org/lang_transaction.html)、[RFC 8246 immutable](https://www.rfc-editor.org/rfc/rfc8246.html#section-2)、[Go ServeContent 条件请求](https://pkg.go.dev/net/http#ServeContent)。
