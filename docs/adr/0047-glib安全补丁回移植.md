# ADR-0047：glib 安全补丁回移植

## 背景（Context）

用户于 2026-10-20 要求修复最后的 glib 告警。Tauri 2/GTK3 仍要求 0.18，官方该系列无修复版；直接升级 0.20 不兼容，迁移 GTK4 将改变现有桌面栈。

## 决策（Decision）

对官方 glib 0.18.5 归档回移植上游 #1343 的两行可变出参修复，以 Cargo path patch 覆盖现有依赖。保留版本、MIT 许可及原始文件，用来源哈希与 Linux release 测试核验；不忽略或手工关闭告警。仅修复既有依赖，不引入新框架。

## 状态（Status）

Accepted；范围限本次上游安全补丁。用户同时要求停用 Dependabot 自动升级 PR；漏洞告警和安全 CI 保留。

## 后果（Consequences）

`desktop/vendor/` 增加约 1.7MB 源码维护成本；`desktop/src-tauri` 保持原 API/ABI。`tools/check_glib_patch.py`、安全 CI 核验来源并复现原版失败/修复版通过。官方兼容修复或 Tauri 稳定迁移可用时评估并整件删除补丁快照与专属门禁。同步 desktop README、SECURITY、ARCHITECTURE §10、HANDOVER 及本索引。
