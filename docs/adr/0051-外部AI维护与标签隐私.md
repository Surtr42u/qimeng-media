# ADR-0051：外部AI维护、持久任务与标签隐私

## 背景（Context）

用户2026-11-06确认，混合媒体下载后的来源核对、命名和资料维护交给外部AI，要求后台执行、双端可用，未来媒体驻留NAS。标签需要加密及外发最小化，后续重构须保留该需求。

## 决策（Decision）

基于正式API和领域服务提供独立工具适配、可发现规则包与持久后台任务，AI客户端和模型提供方可替换。规则包解释头像、链接、简介、译文及关联写法。标签采用可信端加密与受限解密，外部默认使用不透明ID/代号。加密选型、密钥和备份迁移先完成设计与验证。手机/电脑阶段提供后台桥接，NAS阶段由常驻执行器调用云端模型。

本决策部分修订ADR-0002的AI范围，允许外部识图与研究辅助维护。原生人脸聚类等其他范围继续沿原决策。

## 状态（Status）

Accepted。用户已确认方向，工具、后台队列及标签加密处于待实现状态。

## 后果（Consequences）

分阶段验收，保留身份、人工资料、事件及备份语义。实施影响OpenAPI、SDK、服务端编排、双端任务入口与安全/迁移机制。要求见[任务书](../AI_MAINTENANCE_TASKBOOK.md)，状态同步CAPABILITY_MAP、HANDOVER、PROJECT_PLAN及SECURITY。
