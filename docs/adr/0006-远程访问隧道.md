# ADR-0006：远程访问只走隧道（Tailscale/WireGuard）

- 状态：已接受（2026-08-22）

## 决策

服务端永远只监听内网 HTTP。异地访问 = NAS 与手机/电脑都装 Tailscale（或自建 WireGuard），登录同账号组成虚拟内网。**禁止**公网端口映射、禁止自管 HTTPS 证书直接暴露服务。

## 理由

- 自托管社区验证的共识方案：加密与身份由隧道层保证，服务端代码零改动（开发期/内网期/远程期同一份代码）
- 公网自曝 = 攻击面从"局域网几十台设备"扩大到"全网扫描器"，且证书续期/漏洞响应全是单人背不动的运维负担
- 免费档 Tailscale 足够个人 3-5 台设备组网

## 带宽注意

远程上行带宽（家宽一般 30-100Mbps）可能低于 4K 原盘码率（50-80Mbps）。缓解顺序：按需缩放端点（图片已内置）→ M6+ 的视频按需转码档位。协议已预留，不急。
