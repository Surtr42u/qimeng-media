# ADR-0031：Android App 全新设计语言「流光玻璃」（液态玻璃质感 + M3 Expressive 动效 + 暗色优先）

## 背景（Context）

M4 App 端按 ADR-0014 落地后，视觉沿用旧项目「中性极简灰」色板（Color.kt 逐行对照旧 colors.xml），信息架构与功能已全（M0–M6 收官）。本项目定位媒体全存 NAS 的多端媒体库，核心场景=媒体库浏览/检索/播放/上传归档/行为数据——消费场景下旧灰系观感平淡，与 Jellyfin/Immich 及 iOS 26 Liquid Glass 等当代媒体应用的设计水位有代差。任务要求：设计语言级重做（非局部美化），功能守恒（页面/路由/交互语义一个不少），技术边界不动（Compose M3 + feature→core 单向依赖，ADR-0008/0014；UI 不碰网络与业务规则；不引白名单外重依赖）。

备选：① 引 haze 等 backdrop-blur 三方库（白名单外重依赖，否）；② 升级 material3 到 1.5 线拿 Expressive（已在用 1.5.0-alpha28，零成本）；③ 纯换色板（不满足"设计语言级"）。

## 决策（Decision）

自建设计语言「流光玻璃」，落点分四层：

1. **色彩**：暗色为第一基准（媒体消费暗色优先；主题仍跟随系统，深浅两套同源设计，不新增主题开关功能）。暗色基底=深蓝紫夜色（近黑非纯黑，层进 surface 阶梯），主色=鸢尾蓝紫（iris），强调=极光青（aurora teal）与霞粉（blossom）三元；浅色=冷瓷白 + 同族低饱和。品牌色单源 `QimengBrandColors`（core:ui/theme/Color.kt 全量重写，旧灰系 token 移除）。
2. **玻璃质感（自建，零新依赖）**：官方 Compose 无 backdrop-blur API（已核官方文档/生态现状，haze 系为三方方案不取）。实现路径=「分层半透明 + 受光描边 + 高光 + 深色投影」的 `GlassSurface` 组件族（core:ui/glass）+ **环境辉光**（`AuroraBackdrop`：自带内容的径向渐变辉光团做"被磨砂的景深"，玻璃面板覆于其上即成磨砂观感——辉光本体是自绘内容，不需采样背后像素，全 API 级别一致）；对**自有内容**（头图/氛围层）用 `Modifier.blur`（API 31+ RenderEffect）做真模糊。**降级策略**：API < 31 `Modifier.blur` 为 no-op，所有玻璃面板天然回落「半透明纯色层+阴影」（不透明度取值保证无模糊时文字对比度仍达标），无需分支代码。
3. **动效（M3 Expressive + spring 物理）**：主题换 `MaterialExpressiveTheme` + `MotionScheme.expressive()`（material3 1.5.0-alpha28 已具备，官方 API）；覆盖页（pushed 路由）转场从 snap 瞬切换 spring 物理滑入（横滑+淡入，详情页缩放入场）；按压微交互统一 spring 缩放（`Modifier.pressScale`）；**Tab 切换保持 snap 瞬切不动**——常驻层防闪烁机制（NavHost 空壳跳板 + 乐观翻转）依赖瞬时交换，spring 化会复活已根修的叠影/闪烁问题。SharedTransitionLayout 评估后不取：真实 Tab 屏在常驻层渲染于 NavHost 之外，跨路由共享元素无载体，收益仅剩 pushed→detail 一段，风险/收益不成立。
4. **形状/排版/组件**：大圆角语言（卡 20dp、面板 24dp、胶囊 100dp 不变）；页面大标题 Display 档；共享组件（QimengSegPill 胶囊、骨架屏、TopBar、媒体卡）换装新 token；壳层底栏换自绘玻璃导航栏（GlassNavBar，视觉重做、点击/防抖/双击回顶/常驻层逻辑逐字不动）。

范围纪律：只动 `android/core/ui`（主题/玻璃件/共享组件）+ `android/app`（导航壳视觉与转场）+ 各 feature 渲染层（Screen/组件文件），ViewModel/Repository/SDK/协议/路由字符串零改动；`BiliPlayerView`/`ZoomImageView`（ADR-0014 桥接件）与详情沉浸状态机不碰视觉逻辑，仅色值适配。

## 状态（Status）

Accepted（2026-10-02）

## 后果（Consequences）

- **积极**：媒体应用当代观感（暗色玻璃 + 辉光景深）；UI 仍是"最便宜可换的层"（ADR-0008），逻辑层零触碰；无白名单外依赖；API 26–30 自动降级不崩。
- **代价/风险**：旧灰系 token 全量退役，`QimengBrandColors` 消费点（QimengNavHost 底栏指示器、TimelineTagColors）须同步改；半透明面板对无障碍对比度需自查；expressive spring 的动能观感需走查校准（过弹则调 dampingRatio）。
- **受影响文件**：`android/core/ui/src/main/java/media/qimeng/app/core/ui/theme/*`（Color/Theme/Type/Dimens）、`android/core/ui/.../glass/*`（新）、`android/core/ui/.../component/*`（换装）、`android/app/.../navigation/QimengNavHost.kt`、`android/feature/*/…Screen.kt`（渲染层）、`docs/adr/INDEX.md`、`docs/HANDOVER.md`、`docs/CHANGELOG.md`、`android/README.md`。
- 明确不做：主题手动开关（无既有功能，不擅自加）、backdrop 采样式模糊（无官方 API，降级路径已覆盖）、跨路由共享元素（见上）、Web/桌面端（本 ADR 仅 Android）。
