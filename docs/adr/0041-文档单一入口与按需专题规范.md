# ADR-0041：文档单一入口与按需专题规范

## 背景（Context）

根入口和协作规范重复必读链，交接重复架构/能力，领域/API 大文件难以按任务读取；历史覆盖式补丁和重复事实已导致文档漂移。用户要求彻底优化文档体系，保持代码不变。

## 决策（Decision）

1. AGENTS 为唯一全量必读入口，协作细则按任务章节读取；明确扩读条件，允许必要的完整源码阅读，禁止默认通读全部 ADR/历史。
2. DOMAIN_RULES 和 GUIDE_API 保留为兼容目录；领域按专题分拆、原 §编号保留，公式/常量原文不变；API 按端点族组织并将有效修订并入对应正文。
3. 架构、领域、安全、能力、当前事项、里程碑各维护自身事实，其他文件短述并链接；权威按职责判定，明确有效版本与取代状态。
4. 本仓 GUIDE_UI 整理已记录的现行交互约束；旧仓规格仅历史来源，不再强制依赖仓外文件，未覆盖行为按实际需求核实。
5. CHANGELOG 保留最近 30 笔，旧条目完整原样归档，history/INDEX 维护范围；llms.txt 只导航，删除易漂移事实副本。
6. 文档变更按影响检查路径/锚点/内容守恒/现行口径/敏感串；不要求应用构建。详细维护规范在 AI_README_FIRST「文档维护」。

## 状态（Status）

Accepted（2026-10-19，用户授权执行文档体系优化）。

## 后果（Consequences）

减少固定读取负担，专题文件数增加但任务只读命中范围；旧入口与章节编号可继续定位。不得把拆分当作规则简化或功能变更；历史是溯源材料，不覆盖当前规范。仓内 UI 约束不是旧交互全量复刻承诺。没有新运行时依赖、协议/schema/代码变更。
