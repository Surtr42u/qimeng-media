## 2. 行为变化说明（用户可感知面）

- **全部改动对默认配置/常规操作零行为变化**，除以下改善：
  - Web 相册/搜索/收藏/集合页换筛选时不再闪「加载中」（保留旧列表平滑过渡）；
  - 换搜索词不再多打一针无效请求；我的页进页少打 4 针请求；
  - 大列表滚动/面板开合更顺滑（重渲染大幅减少）；
  - 登录失败时能分清「密码错」还是「连不上服务器」；
  - 手误的 `?tab=xxx` 不再显示成 COS 页；
  - Android 备份导入大文件不再有卡死风险；全库预取内存峰值大幅下降；
  - 服务端 `thumbnail.long_side` 非 512 配置从下个构建起真正生效（此前静默失效）。
