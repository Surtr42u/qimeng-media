# CAPABILITY_MAP - 能力与缺口

> 新功能提案先查本表和相关 ADR。每域只维护能力状态/缺口，机制详情链接专题；当前事项见 HANDOVER。维护日期：2026-10-22。

## 状态口径

**已有**表示已交付功能，不代表所有异常、硬件和迁移路径均已验收；**部分已有**区分可用基座与待完善项；**规划中**写触发条件，不承诺日期；**明确不做**须有决策依据。三端差异及实测范围单独说明，禁止把设计当实现或把自动化当设备验收。

当前维护优先保障 PC 服务端/Web/PWA、arm64 Android 连接/内嵌与 Windows 桌面薄壳；Termux 为既有可选路径，不因本轮维护擅自删除。qimeng_api35 用于连接模式验证，x86_64 内嵌为已知失败路径；未来 NAS/arm64 镜像和其他平台按实际需求另验收。2026-10-21 用户要求 NAS 测试暂不执行。本轮维护已结项，用户已自行测试手机并要求删除临时清单；后续状态见 [HANDOVER](HANDOVER.md)，用户不承担手动维护步骤。
